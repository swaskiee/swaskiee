## How I think

| 01 · Understand | → | 02 · Reason | → | 03 · Predict | → | 04 · Impact |
| --- | --- | --- | --- | --- | --- | --- |
| Raw data → clean data → patterns | | Statistics → relationships → signals | | Features → models → evaluation | | Insight → decision → outcome |

```python
def approach(raw_data):
    clean      = understand(raw_data)      # remove noise, spot patterns
    signals    = reason(clean)             # statistics, relationships
    prediction = model(signals)            # features, evaluation
    decision   = act_on(prediction)        # insight becomes outcome

    return decision   # useful > impressive
```

## Featured builds

### [Olist Brazilian E-Commerce Analytics Engine](https://github.com/swaskiee/Olist-Brazilian-E-Commerce-Analytics-Engine)
An end-to-end analysis of **99,441 marketplace orders** to find what really drives customer dissatisfaction on Olist. Built for the Data Analytics Hackathon by Gradient Learnings (team GenWin, as team leader).

- **The delivery cliff:** low-review rate jumps from **9.1%** (on-time or early) to **45.9%** (late)
- **Root cause:** logistic regression shows a late delivery makes a 1-2 star review **6.66x** more likely, the largest driver of all factors tested
- **Beyond the numbers:** multi-seller baskets, geographic supply concentration (70.8% of sellers in São Paulo) and NLP on 41,000+ Portuguese reviews, ending in a three-pillar operational roadmap

`Python` `Pandas` `Statsmodels` `Scikit-learn` `NLP` · [Report](https://github.com/swaskiee/Olist-Brazilian-E-Commerce-Analytics-Engine/blob/main/Olist_Analysis_Report.pdf) · [Executive deck](https://github.com/swaskiee/Olist-Brazilian-E-Commerce-Analytics-Engine/blob/main/Olist_Marketplace_Analysis_Presentation.pptx)
